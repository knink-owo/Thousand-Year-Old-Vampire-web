# 国际化（中 / 英）

界面与游戏内容都支持中英切换，默认英文。数据管线见 [pipeline.md](pipeline.md)。

## 三条不变量

1. **界面文案不硬编码在组件里**：模板中出现中文字面量即测试失败，必须走 `t('key')`。
2. **每种语言一份提示包**，由 `meta.language` 标识；两包条目数、效果类型序列必须逐条相同。
3. **引擎与 `GameState` 不存"待翻译"的界面文案**；玩家写下的内容（经历、日记、结局原因）一经写入即定格。

## 三层

| 层 | 内容 | 位置 | 切换语言时 |
|---|---|---|---|
| 界面文案 | 按钮、标签、弹层、效果说明 | `src/i18n/{zh,en}.ts` | 立即重渲染 |
| 游戏语料 | 80 条提示、教程正文 | `src/data/official-pack*.json`、`src/content/tutorial.*.ts` | 整包热替换，停留在同一提示 |
| 玩家产物 | 经历、日记、系统日志、结局 | `GameState`（localStorage） | **保持原样** |

## 目录与 API

```
src/i18n/
  types.ts   MsgKey（= keyof typeof zh）/ Messages
  zh.ts      中文文案（唯一来源）
  en.ts      const en: Messages —— 少一个键就编译报错
  index.ts   locale / t() / setLocale() / applyDocument()
src/content/
  types.ts          Chapter 结构
  tutorial.zh.ts    教程（中文）
  tutorial.en.ts    教程（英文，取自原书）
```

- `t(key, params?)` 在渲染期读取 `locale.value`，模板因此自动建立依赖；`{name}` 形式占位符由 `params` 替换。
- 未定义的键会回退为键名本身，便于发现遗漏。
- 新增文案：先加 `zh.ts`，`en.ts` 缺键会直接编译失败。

## 默认语言与检测

`detectLocale()` 的顺序：

1. URL 参数 `?lang=zh|en`（可分享链接）
2. `localStorage['tyov:lang:v1']`
3. **有旧存档且无偏好 → 中文**（英文版上线前的存档都是中文写的，避免老玩家语言突变）
4. 其余 → 英文

`setLocale()` 写入偏好、更新 `<html lang>` 与 `document.title`，并触发 store 重新解析提示包。

## 切换时的行为

| 场景 | 结果 |
|---|---|
| 首页 / 建卡 / 教程 | 全量更新 |
| 游戏中 | 当前提示正文、效果说明、按钮更新；已写经历与日记保持原语言 |
| 历史 / 回顾 | 记录本身不重绘 |
| 自定义提示包 | `meta.language` 与当前语言不符时回落内置包 |

系统日志（掷骰、获得技能等）在**写入时**按当时语言定格，不做事后重绘：一是那段历史就该保持原样，二是省掉给 `GameState` 增加 `key/params` 的存档迁移。

## 守卫

| 测试 | 断言 |
|---|---|
| `i18n.test.ts` | 中英键集合相等；英文值不含中文（`lang.zh` 豁免）；插值可用 |
| `template-guard.test.ts` | 所有 `.vue` 的模板块内无中文字面量（注释与插值除外） |
| `pack.parity.test.ts` | 双语包结构逐条对等；英文包无中文残留 |
| `verify_bilingual.py` | 每条英文都能在英文原文中逐字命中（防"翻译回去"） |

测试通过 `vite.config.ts` 的 `setupFiles` 固定为中文（`src/test/setup.ts`），因此既有中文断言不受产品默认语言影响；需要英文的用例在测试体内自行 `setLocale('en')`。

## 已知取舍

- 英文比中文长约 30–60%，窄按钮需要逐屏确认换行（`btn`、面板 tab）。
- 单个 `official-pack` 约 75 KB，两份都进包：在线版 391 KB JS（gzip 127 KB），单文件版随之增大。
- 教程英文正文是原书文字的逐字摘录，版权归属见 [NOTICE.md](../NOTICE.md)。
